### 🌟 Proyectos Destacados del Portafolio

#### 🛒 [LowriCo](https://github.com/JonathanC0409/LowriCo)
> **ERP & E-Commerce Empresarial de Alto Rendimiento**  
> Plataforma completa de gestión de negocios y comercio electrónico. Cuenta con módulos de finanzas (ingresos, abonos, cartera, márgenes de ganancia con exportación PDF/Excel), auditorías con escalas Likert, gestión de despachos con cálculo de tarifas de envío, automatización de notificaciones y portal de cliente interactivo.  
> `Laravel 12` • `Livewire 4` • `Flux` • `Docker` • `Supabase / PostgreSQL` • `Render`

#### 📱 [Deuna Impulsa 360](https://github.com/JonathanC0409/deuna-impulsa-360)
> **MVP Fintech Móvil con Gamificación (Proyecto Hackathon)**  
> Aplicación móvil diseñada para MIPYMES que integra la pasarela de pagos Deuna con mecánicas de fidelización gamificada (ruleta de premios, recompensas y promociones) y panel de analítica para comerciantes.  
> `React Native` • `Expo` • `JavaScript` • `Fintech` • `Gamification`

#### 🧠 [VitaMind](https://github.com/JonathanC0409/VitaMind)
> **Plataforma HealthTech con Búsqueda Semántica y Agentes de IA**  
> Sistema de salud mental y bienestar que integra inteligencia artificial para consultas asistidas con agentes, búsqueda semántica avanzada en registros clínicos, chatbot conversacional y métricas operativas del sistema.  
> `ASP.NET Core Web API` • `ASP.NET MVC` • `Entity Framework` • `AI Agents` • `Semantic Search`

#### 🏫 [Pequeños Exploradores](https://github.com/JonathanC0409/pequenos-exploradores)
> **Sistema Integral de Gestión Escolar y Comunicación en Tiempo Real**  
> Solución orientada a centros de educación infantil con backend modular en Node.js y frontend reactivo en React + Vite. Incluye gestión de docentes, períodos lectivos, comunicados oficiales, encuestas institucionales y control de accesos con JWT.  
> `Node.js` • `Express` • `React` • `Vite` • `PostgreSQL` • `JWT` • `Vercel`

#### 🚛 [Sistema de Gestión de Flotas y Mantenimiento Predictivo](https://github.com/JonathanC0409/Sistema-de-Gesti-n-de-Flotas-y-Mantenimiento-Predictivo)
> **Gestión Logística y Monitoreo con Telemetría IoT**  
> Arquitectura orientada a servicios dividida en API principal de control vehicular (camiones, talleres, conductores, calendarios de mantenimiento) y API especializada de telemetría de sensores y alertas tempranas de averías.  
> `C# .NET` • `Web APIs` • `Arquitectura en Capas` • `Simulación IoT`
